# Week 3 EX02

## Project Title

**Week 3 EX02 - Sushi Fighting Game**

A two-player fighting game created with p5.js and p5.sound. Each player controls a sushi fighter, moves around the stage, jumps, attacks, blocks, and tries to win the match.

## Setup and Interaction Instructions

To run the sketch locally, open `index.html` in Google Chrome using Live Server.

**Player 1 Controls:**

- Move: A / D
- Jump: W
- Attack: F
- Block: S

**Player 2 Controls:**

- Move: Left Arrow / Right Arrow
- Jump: Up Arrow
- Attack: K
- Block: Down Arrow

Press **ENTER** to start or rematch.

**Opening the Chrome Console**

- **Windows:** Press `F12` or `Ctrl + Shift + J`, then click the **Console** tab
- **Mac:** Press `Cmd + Option + J`

The console will show any errors in your sketch.
